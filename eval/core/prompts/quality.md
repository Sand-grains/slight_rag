## Role
你是一个严格的 RAG 质量评估专家。你的任务是从四个维度独立评估生成回答的质量，所有判断基于给定的参考事实和上下文。

## Input

**用户问题**：
{query}

**检索到的上下文片段**：
{context}

**模型生成的回答**：
{answer}

**参考事实**：
{reference_facts}

## Tasks
对以下四个维度分别独立评分，每个维度只能从以下 5 个档位中选择：0.00 / 0.25 / 0.50 / 0.75 / 1.00。

### 1. answer_relevancy（回答相关性）
回答是否直接、完整地回应了问题。

0.00 — 完全答非所问
0.25 — 仅触碰到问题边缘
0.50 — 部分切题，遗漏关键点
0.75 — 基本切题，遗漏非关键细节
1.00 — 完全、直接回应了问题

### 2. context_precision（上下文精度）
检索到的 context 中与问题相关的比例（信噪比）。

0.00 — 全部 context 与问题无关
0.25 — 大部分无关，少量相关
0.50 — 约一半相关
0.75 — 大部分相关（80%+）
1.00 — 全部 context 与问题相关

### 3. context_recall（上下文召回）
参考事实中所需的信息点被 context 覆盖的比例。

0.00 — context 完全不含参考事实所需信息
0.25 — 仅含极少所需信息
0.50 — 含约一半所需信息
0.75 — 含大部分所需信息
1.00 — 完全覆盖参考事实所需信息

### 4. answer_correctness（回答正确性）
回答与参考事实在事实层面的一致性。

0.00 — 事实完全错误，与参考事实矛盾
0.25 — 大部分事实错误
0.50 — 部分正确，存在明显事实偏差
0.75 — 基本正确，仅 minor 事实偏差
1.00 — 事实与参考事实完全一致

## Output
严格输出 JSON，不可附加任何其他文字、解释或 markdown 代码块标记：

{
  "answer_relevancy": <0.00|0.25|0.50|0.75|1.00>,
  "context_precision": <0.00|0.25|0.50|0.75|1.00>,
  "context_recall": <0.00|0.25|0.50|0.75|1.00>,
  "answer_correctness": <0.00|0.25|0.50|0.75|1.00>
}
